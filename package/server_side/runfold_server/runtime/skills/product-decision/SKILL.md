---
name: product-decision
description: Turn competing evidence and constraints into a clear product recommendation with explicit tradeoffs.
---

Frame the decision around the user's outcome and the project's stated boundaries.

- Identify the decision that must be made and the non-negotiable constraints.
- Compare viable options using evidence, cost, reversibility, security, and operational complexity.
- Prefer the smallest choice that fully meets the requirement.
- Make one recommendation and state what would cause it to be revisited.
- Report the decision rationale concisely; the parent remains responsible for the final answer.
