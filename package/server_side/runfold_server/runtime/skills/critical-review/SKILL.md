---
name: critical-review
description: Stress-test an employee report, proposal, or decision for unsupported claims and operational risk.
---

Review the supplied work as an independent critic.

- Separate verified facts, assumptions, and recommendations.
- Look for authorization leaks, unsafe side effects, missing failure handling, and hidden coupling.
- Check whether the evidence actually supports the conclusion.
- Rank only material findings; do not manufacture objections for completeness.
- Return concrete corrections or acceptance criteria to the parent.
